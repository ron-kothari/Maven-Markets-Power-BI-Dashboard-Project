## 📝 Overview

A Power BI dashboard built for Maven Market, a fictional supermarket chain with stores across the USA, Mexico, and Canada. Page one gives a topline view of the business, covering monthly profit, transactions, and returns against goal, a regional sales map, and a product brand table ranking performance by profit margin and return rate. Page two drills into product level detail, tracking individual product transactions and returns alongside monthly and weekly revenue trends. Both pages are fully interactive and built on the same Power Query, data modeling, and DAX foundation.
